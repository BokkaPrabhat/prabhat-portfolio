# Prabhat Bokka — Portfolio
## Run locally
- Extract the ZIP.
- Open `index.html` in a browser, or use VS Code Live Server.
- No npm install/build step is required.

## Personal files to add
1. Your uploaded portrait is included as `img/profile.png` and is used in the page.
2. Your uploaded DOCX resume has been exported to `resume.pdf` in the project root. Review the PDF before publishing.
3. Replace “Profile link to be added” with your GitHub profile once you share it.
4. Add project demo/source links only after confirming the correct URLs.
5. Add your public email address if you want it displayed.

## Design / functionality
- Dark navy + cyan theme, optional light mode
- Responsive navigation with mobile menu
- Typing animation for role titles
- Scroll reveal animations and animated skill bars
- Active section highlighting
- Netlify-compatible contact form

## Contact form
The form is configured for Netlify Forms. It will not send messages in a local preview. After deploying to Netlify, verify form detection in the Netlify dashboard.

## Deploy
For a simple static deployment, upload the extracted folder to Netlify. No build command is required; publish directory is the project root.
